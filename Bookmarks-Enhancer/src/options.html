Bookmarks Enhancer

Getting started

  1. Open Bookmark Rules and map bookmark folders to styles (for example Blocked or Favorited).
  2. On a site, right-click and choose Select Target Classes, or add Search Pairs under Site Rules.
  3. Save, then reload the page (or click the toolbar icon) to apply styles to matching bookmarks.

Optional: use Text Rules to style elements by keywords, and URL Parameter Rules when bookmark links include extra query params.
