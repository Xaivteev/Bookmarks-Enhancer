Bookmarks Enhancer

Getting started

  1. Open if you want names besides Blocked, Favorited, and Seen.
  2. On a site, right-click and choose Select target classes, or add the hostname under .
  3. Open that site to set class groups, saved links, and text rules. Right-click a link or page and choose Add link to list or Add page to list to save it under a look.
  4. Save — open tabs update on their own.

Optional: on a site, set URL parameters to keep when matching links that include extra query params.
