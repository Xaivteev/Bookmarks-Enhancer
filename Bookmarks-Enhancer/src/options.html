Bookmarks Enhancer

Getting started

  1. Open if you want names besides Blocked, Favorited, and Seen.
  2. On a site, right-click and choose Select Target Classes, or add the hostname under .
  3. Open that site to set class groups, saved links, and text rules. Right-click a link or page and choose Add to list to save it under a look.
  4. Save — open tabs update on their own.

Optional: on a site, set URL parameters to keep when matching links that include extra query params.

Import from bookmarks

Choose a bookmark folder and a look. Each website found in that folder (including nested folders) is added under Sites, and its links are saved under that look. Save afterwards to apply.

Includes the selected folder and all folders inside it.

Define named looks used by saved links and text rules on each site. Choose a predefined look (Blocked / Favorited / Seen) or Custom CSS declarations applied to matching elements. Assign a unique shortcut icon and color to show a toggle in the top-right of matching sites. Icons cannot be reused, so at most five looks can have shortcuts — other looks stay on the context menu.
